# zh → en Translation Review Guide

A reusable review workflow for translating Chinese technical documentation into English.

## Usage

1. Copy [`zh-en-review-workflow.md`](./zh-en-review-workflow.md) into your documentation repo (e.g. `.github/`) or reference it directly from here.
2. Fill in the **Repo-specific configuration** section at the bottom of the file with your project's directory layout and glossary.
3. Follow the review steps for each document.

## What the guide covers

- 12 review requirements covering completeness, precision, natural English, terminology, source correspondence, evidence matching, and executable examples.
- 5 ordered review steps from first read-through to final reporting.
- A template slot for per-repo configuration (paths, glossary, validation commands).

## Contributing

Improvements to the generic principles (requirements 1–12 and the steps) are welcome. Keep repo-specific details out of this shared guide.
